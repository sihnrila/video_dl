# CHZZK & SOOP DL (치지직 & 숲 다운로더) 🌲🎬

치지직(CHZZK)과 숲(SOOP, 구 아프리카TV)의 VOD 및 라이브 영상을 초고화질로 손쉽게 다운로드할 수 있는 **데스크톱 애플리케이션(Electron) 및 크롬 익스텐션 통합 다운로더**입니다.

---

## ✨ 주요 기능

### 1. 강력한 멀티플랫폼 지원
* **네이버 치지직**: 고화질 VOD / 클립 다운로드 및 라이브(생방송) 녹화 지원
* **숲 (SOOP)**: 고화질 VOD 다운로드 및 라이브 녹화 지원

### 2. 크롬 익스텐션 & 데스크탑 앱 실시간 양방향 연동
* **실시간 진행 상황 동기화**: 크롬 익스텐션에서 시작한 백그라운드 다운로드 작업이 데스크탑 앱 화면 하단에 실시간 진행 바(%)와 실시간 최신 로그로 즉시 연동됩니다.
* **팝업 닫힘 방지 및 자동 상태 복구**: 사용자가 브라우저 빈 곳을 눌러 익스텐션 팝업이 강제로 닫혀도 백그라운드(Service Worker)가 계속 트래킹하며, 다시 열었을 때 완벽하게 진행률이 복원됩니다.
* **비동기 파일 자동 저장**: 팝업이 닫힌 동안 다운로드가 완료되면, 팝업을 다시 여는 즉시 다운로드 완료 알림과 함께 PC 저장 창이 자동으로 호출됩니다.
* **양방향 완료물 저장**: 익스텐션을 통해 완료된 영상도 데스크탑 앱 화면에서 `⬇️ 내 PC에 저장` 버튼을 통해 자유롭게 로컬 디스크에 영구 소장할 수 있습니다.

### 3. 세션 쿠키 완벽 자동화 및 연동
* **크롬 세션 쿠키 자동 캡처**: 크롬 익스텐션이 사용자의 로그인 세션 쿠키(치지직 `NID_AUT/NID_SES` 및 숲 `PHPSESSID`)를 백그라운드에서 자동으로 감지해 백엔드로 전송합니다. 성인인증 제한 영상이나 구독자/멤버십 전용 VOD도 별도 쿠키 복사 없이 원클릭 다운로드됩니다.
* **동적 쿠키 분리 UI**: 플랫폼(치지직/숲) 입력 URL 감지에 맞춰 쿠키 수동 지정 가이드와 입력란이 똑똑하게 자동 전환됩니다.

### 4. Zero-Setup 데스크탑 앱 (Electron)
* **바이너리 자동 관리**: 사용자의 OS(Windows/Mac)를 자동 감지하여 최신 `yt-dlp` 실행 파일을 백그라운드에서 무중단 자동 다운로드 및 업데이트합니다.
* **FFmpeg 내장**: `ffmpeg` 바이너리가 프로그램 패키지 내부에 자동 탑재되어 있어, 별도의 설치나 환경 변수 세팅 없이 최고 품질의 비디오와 오디오가 완벽하게 무손실 합병(Merge)됩니다.

## 💻 빌드 및 실행 방법

### 1. 사전 준비 (개발자용)
- [Node.js](https://nodejs.org/) (버전 18 이상 권장)

### 2. 패키지 의존성 설치
```bash
npm install
```

### 3. 개발 모드로 데스크탑 앱 로컬 실행
```bash
npm run start:electron
```

### 4. 데스크톱 앱(설치 파일) 패키징 빌드
현재 개발 환경의 운영체제에 맞는 단독 실행 설치 파일(`.dmg`, `.exe`)을 `dist` 디렉토리에 빌드합니다.

* **Mac용 빌드 (.dmg)**
  ```bash
  npm run build:mac
  ```
* **Windows용 빌드 (.exe)**
  ```bash
  npm run build:win
  ```

> [!WARNING]
> **크로스 컴파일(교차 빌드) 주의사항**
> Mac 환경에서 Windows용 빌드(`npm run build:win`)를 수행하면 내장되는 FFmpeg 바이너리의 아키텍처 불일치로 인해 윈도우에서 합병 처리가 실패할 수 있습니다. 완벽한 Windows 배포 빌드를 얻으려면 가급적 실제 Windows PC에서 소스코드를 받아 `npm install` 후 `npm run build:win`을 진행할 것을 강력히 권장합니다.

## 📁 디렉토리 구조 설명
- `server.js`: 백엔드 다운로드 파이프라인 제어 및 로컬 API (Express) 서버
- `main.js`: Electron 데스크톱 앱 창 제어 및 라이프사이클 관리 메인 프로세스
- `ytdlp-manager.js`: OS에 맞춰 최신 `yt-dlp` 바이너리를 자동 업데이트하는 엔진 매니저
- `public/`: 프리미엄 다크 글래스모피즘 스킨이 탑재된 React 기반 앱 화면 소스
- `chzzk-extension/`: 크롬 브라우저 실시간 도메인 감지 및 백그라운드 무손실 다운로드 브릿지 크롬 익스텐션
